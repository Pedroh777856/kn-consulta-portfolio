# Materiais de portfólio — KN Consulta

## Descrição curta
KN Consulta é uma demonstração em JavaScript para consultar registros em lote, consolidar históricos operacionais e destacar pontos de atenção, com dados fictícios e exportação para CSV.

## Descrição longa
O KN Consulta apresenta uma proposta de automação para apoiar a análise operacional e a rastreabilidade. A partir de uma lista de identificadores demonstrativos, a aplicação reúne movimentações, responsáveis, equipes, etiquetagem e inventário em uma visão organizada.

A camada de análise calcula intervalos entre etapas, identifica status consecutivos repetidos, sinaliza informações ausentes e compara a última etiquetagem com a última movimentação para despacho. A exportação produz uma linha por registro, incluindo o histórico detalhado para análise em planilhas.

Esta versão foi reconstruída para portfólio com dados inteiramente fictícios e processamento local. Ela demonstra a lógica de consolidação e análise sem acessar sistemas internos. O objetivo é reduzir etapas manuais de organização e ampliar a clareza na revisão de registros; os ganhos de tempo ainda precisam ser medidos em um cenário autorizado.
