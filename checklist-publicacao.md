# Checklist de publicação

## Preparação do pacote
- [ ] Abrir demo.html e analisar os três casos fictícios.
- [ ] Exportar CSV e conferir acentos, colunas e histórico.
- [ ] Confirmar que todo material continua usando IDs DEMO, operadores e equipes genéricos.
- [ ] Revisar autoria e datas nos textos do portfólio.
- [ ] Definir licença e atribuição antes de publicar o código.
- [ ] Produzir capa usando capa-briefing.md ou captura exclusiva da demo.
- [ ] Conferir que nenhuma captura mostra abas, URLs, notificações ou dados internos.

## GitHub / portfólio — após autorização de publicação
- [ ] Criar repositório público com README, demo, dados, testes e materiais selecionados.
- [ ] Revisar os arquivos e o histórico que serão enviados.
- [ ] Executar os testes documentados e verificar a demonstração no navegador.
- [ ] Se desejar uma página pública, hospedar a demo estática e verificar os links publicados.
- [ ] Inserir os links públicos reais nos materiais do LinkedIn.

## LinkedIn — somente após autorização do usuário
- [ ] Usuário autoriza o acesso e entra na conta pelo navegador, sem enviar senha no chat.
- [ ] Revisar a descrição do projeto, título e material de Destaques.
- [ ] Incluir o projeto e o link público disponível no perfil.
- [ ] Revisar a prévia do post e da capa antes de concluir a publicação autorizada.
- [ ] Verificar os textos e links no perfil após salvar.

## Após publicar
- [ ] Guardar os links públicos e uma captura do resultado.
- [ ] Registrar eventuais métricas somente quando medidas e documentadas.
- [ ] Atualizar limitações e funcionalidades quando a versão evoluir.

Estado atual: pacote preparado localmente. Nenhum repositório, página ou conteúdo do LinkedIn foi publicado por este trabalho. O próximo passo depende da autorização do usuário para acessar o LinkedIn.
